# Rapor ekranları — #64

27 Kasım 2026. Kapsam, 14 Kasım kararı ve `docs/urun/62-rapor-kabul-ve-sunum-kurgusu.md` ile sınırlıdır: proje ilerlemesi, kişi bazlı tamamlama ve tarih aralıklı ilerleme. Gün/hafta/ay trendleri ve dışa aktarım bu teslimde yoktur.

## Kullanım ve bağımlılık

- Gerçek oturumda **Raporlar** menüsü → proje seçimi → `/uygulama/projeler/:id/raporlar`. Proje ayrıntısında da bağlantı var.
- Proje adı ve erişim, proje ayrıntı API'sinden okunur. Yetkisiz kullanıcıya örnek veri gösterilmez.
- `GET /api/projects/:id/reports/progress`: ilerleme çubuğu, durum sayıları, geciken/atanmamış görevler ve kişi tablosu.
- `GET /api/projects/:id/reports/range?from=&to=`: iki gün dahil, oluşturulan görevler ve dönem içinde en az bir kez tamamlanan farklı görevler. Tamamlanan sayısı oluşturulan sayısından fazla olabilir; güncel Done sayısı değildir.
- #150 (`feature/65-rapor-api`, test edilen commit `7a1dc16`) API bağımlılığıdır. Bu PR birleşmeden develop üzerinde rapor servisi bulunmaz.
- Yenileme güncel raporu getirir; 403/404 sıfır veri sayılmaz. 401 mevcut oturum yönetimini kullanır. Proje değişiminde istekler iptal edilir. Geçersiz aralık önceki sonucu kendi tarih başlığıyla korur.
- Kişi tablosu küçük ekranda kendi bölgesinde yatay kaydırılır; tablo başlıkları, açıklaması ve klavye odağı vardır. Renk tek başına bilgi taşımaz.

## Doğrulama

`npm --prefix client run check`: lint, **101/101** test, TypeScript ve üretim derlemesi geçti. `Reports.test.tsx` R-01..R-07 için UI/sözleşme regresyonlarını kapsar. Bunlar jsdom testleridir.

Gerçek API + PostgreSQL kontrolü, yalnız bu koşu için oluşturulan ayrı `sektech_reports_review_1795808885627` veritabanında, istemcinin gerçek `apiRequest`, `progressReport` ve `rangeReport` koduyla yapıldı:

| Senaryo | Sonuç |
| --- | --- |
| Boş proje | 0 görev, %0 |
| Sabit veri | 10 görev, 4 Done, 3 In Progress, 3 To Do, %40 |
| Geciken | Tamamlanmış eski tarihli görevler hariç 3 |
| Kişiler | İki kişi, her birinde 5 atanan / 2 Done / %40 |
| Aynı gün sınırları | 10 oluşturulan, 4 tamamlanan |
| Yeniden açıp tamamlama | Aynı görev bir kez sayılır |
| Atanmamış görev | Ayrı atanmamış sayısına yansır |
| Projeden çıkarılmış atanan kişi | Kişi dökümünde korunur |
| Üyelik kaldırılmış hesap | 404; veri verilmez |

Bu kontrol tarayıcı E2E veya ürün sahibi kabulü değildir. Ana geliştirme veritabanı sıfırlanmadı.
