# 17 Kasım 2026 — Gerçek dosya ekranı (#57 / #129)

## Kullanım

Gerçek hesapta **Dosyalar → proje seç** veya **Proje detayı → Dosyalar**. Adres: `/uygulama/projeler/:id/dosyalar`.

- Liste: `GET /api/projects/:id/files`; görev seçilirse `?taskId=`. Metadata #132'nin id/project_id/task_id/name/type/size/uploader_id/uploaded_at alanlarıyla doğrulanır.
- Yükle: `POST /api/projects/:id/files`; FormData `file`, isteğe bağlı sayısal `task_id`. Multipart Content-Type/boundary tarayıcı tarafından belirlenir.
- En fazla 10 MiB; pdf/png/jpg/jpeg/docx/xlsx/zip. İstemci boyut ve uzantıyı kontrol eder; içerik imzası ve yetki API tarafından doğrulanır.
- İndir: `GET /api/files/:id/download`, Bearer başlığıyla fetch, sonra blob URL. Token URL'ye konmaz; dosya tarayıcıya indirme olarak iletilir. Başarısız/401/403 yanıt indirme gibi sunulmaz.
- İşlem sürerken ikinci işlem engellenir. Yükleme başarısızsa seçili dosya korunur; otomatik tekrar yükleme yoktur. Bağlantı kesintisinde çift kopya oluşturmamak için listeyi kontrol etme açıklaması vardır.
- Göreve bağlama ve liste filtresi birbirinden bağımsızdır. Görev filtresinde farklı göreve yüklenen dosyanın görünmemesi normaldir; tüm dosyalar filtresinden görülebilir.
- Önizleme `workspace/ProjectFiles.tsx` yerel demo olarak kalır; gerçek hesap `live/ProjectFiles.tsx` kullanır ve örnek veriye geri düşmez.
